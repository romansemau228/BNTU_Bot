# Расписание БНТУ

Telegram Mini App с расписанием занятий БНТУ на 2026–2027 учебный год для первого и второго курсов. Выберите курс, факультет и учебную группу, чтобы посмотреть расписание по дням недели. Для каждой пары отображаются время, название предмета, аудитория и преподаватель; также указаны недели проведения, если расписание чередуется.

Расписание обоих курсов загружается из отдельных Excel-файлов. Приложение учитывает занятия, назначенные сразу нескольким группам. Пользователь может добавить пару на выбранную дату, изменить исходную пару сразу во всём своём расписании или отменить её только на выбранный день; личные изменения сохраняются в Telegram, а вне Telegram — в браузере. Выбранный курс и группа сохраняются отдельно.

В поддерживаемых версиях Telegram Mini App предлагает добавить ярлык расписания на главный экран телефона с логотипом бота.
