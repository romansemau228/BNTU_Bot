# Расписание БНТУ

Telegram Mini App с расписанием занятий БНТУ на 2026–2027 учебный год. Выберите факультет и учебную группу, чтобы посмотреть расписание по дням недели. Для каждой пары отображаются время, название предмета, аудитория и преподаватель; также указаны недели проведения, если расписание чередуется.

Расписание загружается из Excel-файла. Приложение учитывает занятия, назначенные сразу нескольким группам.

**Открыть бота:** [Расписание БНТУ в Telegram](https://t.me/BNTU_Schedule1_bot)
