# Расписание БНТУ

Статическое приложение расписания первого курса БНТУ за 2026–2027 учебный год. Источник расписания — Excel-книга в `data/schedule-source.xlsx`: браузер загружает и читает её напрямую. JSON-файл и сервер для обработки расписания не используются.

## Файлы

- `index.html` — интерфейс приложения и чтение книги Excel в браузере.
- `data/schedule-source.xlsx` — исходная таблица расписания; замените этот файл при обновлении данных.

Для разбора Excel используется библиотека SheetJS, подключаемая с официального CDN. Поэтому при открытии приложения необходимо подключение к интернету.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub и загрузите `index.html` и папку `data` с Excel-книгой.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Дождитесь публикации и откройте адрес вида `https://<имя-пользователя>.github.io/<имя-репозитория>/`.
5. В @BotFather выполните `/mybots` → выберите бота → **Bot Settings → Menu Button**. Укажите надпись кнопки, например `Расписание`, и вставьте адрес GitHub Pages. Также это можно настроить командой `/setmenubutton`.
6. Откройте чат с ботом и нажмите кнопку меню.

Подключение к Telegram не требует токена бота, API или собственного сервера. Для открытия мини-приложения достаточно задать его HTTPS-адрес в BotFather.

Если репозиторий публичный, исходная Excel-книга тоже будет доступна всем.
